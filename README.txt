BatteryVault v1.0.0
====================

Free portable Windows battery health monitor — by VaultSoft.

Portable application — no installation required.

To run:
  Double-click BatteryVault.exe

What it shows (laptops):
  - Battery health % (full charge capacity / design capacity)
  - Design capacity, full charge capacity, capacity wear (mWh)
  - Charge cycle count
  - Current status, charge %, time remaining, charge/discharge rate
  - Health band: Excellent / Good / Fair / Poor

Runs in the system tray. Closing the window keeps it running in the
tray; right-click the tray icon and choose Exit to quit.

No admin rights required. No registry entries are written.
Desktop PCs (no battery) will show "No battery detected".

To uninstall:
  Delete this folder.
